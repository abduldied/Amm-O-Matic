## Requirements

- [Plutonium Launcher](https://plutonium.pw/) with Black Ops II (T6) installed
- Basic familiarity with placing GSC scripts (no coding knowledge required to install)

## Installation

1. Navigate to your Plutonium scripts folder:
   ```
   %localappdata%\Plutonium\storage\t6\scripts\zm
   ```
   If the `scripts` or `zm` folders don't exist, create them.
2. Copy the script file into that `zm` folder.
3. Launch Black Ops II Zombies via Plutonium and load into **Kino Der Toten**.
