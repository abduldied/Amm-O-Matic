# Amm-O-Matic

A custom perk script for **Call of Duty: Black Ops II Zombies**, built for Plutonium T6.

> ⚠️ **Work in progress.** Currently tested on **Kino Der Toten** only. Behavior on other maps is unverified — feel free to test, tweak, and report issues.

![Screenshot](amm-o-matic-screenshot.png)

## What is Amm-O-Matic?

Amm-O-Matic is a cut World at War Zombies perk that maxes out your current weapon's reserve ammo when purchased—giving you an on-demand Max Ammo for high-round survival.The perk was likely scrapped because providing Max Ammo would have undermined the core Zombies mechanic of ammo conservation.

## Requirements

- [Plutonium Launcher](https://plutonium.pw/) with Black Ops II (T6) installed
- Basic familiarity with placing GSC scripts (no coding knowledge required to install)

## Installation

1. Navigate to your Plutonium scripts folder:
   ```
   %localappdata%\Plutonium\storage\t6\scripts\zm
   ```
   If the `scripts` or `zm` folders don't exist, create them.
2. Copy the script file into that `zm` folder.
3. Launch Black Ops II Zombies via Plutonium and load into **Kino Der Toten**.
