## 🚀 Installation Guide

1. Press `Win + R` on your keyboard to open the **Run** dialog.
2. Copy and paste the following path, then press **Enter**:
   ```text
   %localappdata%\Plutonium\storage\t6\scripts\zm
Note: If the scripts or zm folders do not exist, create them manually inside storage\t6\.

Place the script file (.gsc) directly inside the zm folder.

Launch Plutonium BO2 Zombies and load into your map!
